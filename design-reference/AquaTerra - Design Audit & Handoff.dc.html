01 — executive summary

what's actually broken

The prototype is rich and characterful, but it carries three overlapping design languages that drifted apart over time: the original forest-green system, a global "soften everything" override layer, and the current Y2K brutal-scrapbook look. On a single screen you get brutalist 3px-ink feed cards sitting beside soft floating rails, and category colours that collapse into the same blue. This document freezes one system — the Playground direction — and specifies it down to the pixel so it can be built without guesswork.

02 — principles

five rules that keep it AquaTerra

01
Ink outline, hard shadowEvery raised surface has a solid ink border and an offset drop-shadow — never a soft blur. This is the load-bearing motif.
02
Colour = meaningEach of the five verticals owns exactly one hue. Colour is a wayfinding system, not decoration — don't reuse a vertical's hue for anything else.
03
Playful, never sloppyTilts, wobbles and stickers are deliberate and small (≤3°). Fun lives in motion and accents; structure stays rigorous.
04
Three type voicesDisplay (NeutralFace) shouts, Eina01 speaks, mono labels annotate. Instrument Serif italic is the single "human" flourish.
05
Warm paper baseThe cream substrate + subtle noise is non-negotiable. Pure white is reserved for raised cards only.

P0 · fix

Applied in the Playground: ops teal darkened to #12909C (ink passes AA), tomato/green stickers switched to ink text. Standing rule: ink text on green/sky/lemon/tomato/teal; white only on grape at large sizes. For body-size labels on saturated surfaces, prefer ink on a lightened tint.

P0Focus visible

No focus styles exist. Add :focus-visible → 3px grape outline, 2px offset, on every interactive element.

P0Hit targets

Icon buttons are 36–38px. Bump interactive targets to ≥44×44 (bottom-nav, nav icons, act buttons, close ×).

P0Semantics

Icon-only buttons need aria-label; toggles need role=switch/aria-checked; tabs need the tab/tabpanel pattern; feed = <article>.

P1Motion & alt

Honour reduced-motion (§07); every content image needs meaningful alt; decorative stars/doodles get aria-hidden.

12 — content · SEO

voice & discoverability

Microcopy voice

  • lowercase for UI labels & nav ("apply →", "the feed.")
  • Warm, direct, first-person plural ("we read everything").
  • One star ★ glyph as the brand tick — don't over-sprinkle.
  • Numbers stay concrete: "2 min to apply · 24 hrs to hear back".
  • Sentence case in body; Title Case only for proper nouns.

P1 drift: some titles use Title Case + trailing period inconsistently. Pick one (lowercase + period) and apply across all page titles.

SEO provisions P0

  • Per-route <title> + meta description (SPA needs SSR/prerender or head management).
  • One <h1> per page; heading order not skipped.
  • Open Graph + Twitter card image (use brand cover art).
  • Semantic landmarks: header / nav / main / footer.
  • sitemap.xml + robots.txt; the Quick-links page doubles as an HTML sitemap.
  • JSON-LD: Organization, Event (drives), JobPosting (openings), Article (blog).
  • Descriptive alt on all imagery; canonical URLs.
note for eng

This is a client-rendered SPA today. For crawlable content (blog, projects, openings, team pages), plan server-side rendering or static prerendering of those routes — the marketing surfaces need it most; authed app screens (HOD desk, settings) can stay client-only with noindex.

15 — code-level findings

what the prototype's code tells engineering

The prototype is the spec of record for behaviour — but some of its implementation choices are demo shortcuts that must NOT be carried into production.

do not port
  • Demo login — any credentials succeed after a fake 1.1s delay.
  • Artificial 1.6s loading screen (setTimeout) — gate on real data readiness instead.
  • Dead code _animateBigOld() — removed ✓.
  • IDs from Date.now(); volStatus keyed by email — use server ids.
reimplement properly
  • Count-up animations run on 40ms setInterval + setState — use rAF or CSS.
  • Confetti + toast host are appended to document.body imperatively — make them portal components; toast needs role=status live region.
  • Notice-board carousel — now pauses when tab hidden ✓; still honour reduced-motion.
  • Single-toast model drops rapid successive messages — queue them. Toast now has role=status live region ✓.
data model notes
  • Category key drift: ops vs operations both exist (the _cc map papers over it) — pick ONE slug.
  • Post shape is solid (id, author, cat, sticker, link, img, counts) — formalise as the Post entity.
  • Feed images — now get generated alt text ✓; in production alt is an authoring-time required field.
  • Entities to spec server-side: Post, Comment, Member, Team, Project, Opening, Application, Enquiry, Achievement, Product.
