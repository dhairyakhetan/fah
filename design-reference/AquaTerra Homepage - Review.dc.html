1Homepage — consistency & fun review

What's actually broken

The homepage carries three overlapping design systems — the current "Y2K brutal scrapbook" (v6.css), a leftover forest-green system (aq-design-system.css), and a global override layer that strips the bold 2px-ink borders + hard offset-shadows off some cards while leaving them on others. So brutalist feed cards sit next to soft floaty rail cards on the same screen. Categories are muddy too: events, labs and ops all resolve to the same blue.

1a is today, recreated faithfully so the drift is visible. 1b–1d keep the exact same skeleton and content — only the design language changes — so you can judge each direction on equal footing. Every option fixes consistency; they differ in how much fun and where.
