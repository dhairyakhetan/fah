# 02 — better-ui audit (UI polish)

Scope: `frontend/src` excluding `frontend/src/paradox/**`.
Binding context: `REDESIGN_GUARDRAILS.md` (radius scale `--r-sm 20 / --r-md 28 / --r-lg 40 / --r-card 26 / --r-photo 18`; `--shadow-cta` is the only surviving hard shadow, on primary CTAs, stickers and one hero card per screen; everything else flat with a 2px ink border; photos concentric at 8px inset inside a radius-26 card → radius 18; HoD desk is "chrome is brutalist, data is legible").

Audit only — no files were edited. Locations are given by file + selector or quoted string, never line number.

- Read: `styles/tokens.css`, `styles/v6.css`, `styles/routes/{director,feed,home,projects}.css`, `styles/routes/director-people.css`, `components/v6Shared.tsx`, `lib/motion.ts`, `director/adminKit.tsx`, `director/DirectorLanding.tsx`, plus targeted reads of `auth/LoginPage.css`, `components/AQNav.css`, `teams/TeamsPage.css`, `public/OnboardingPage.css`, `feed/PostPage.css`, `director/{ProjectManager,ProjectModal,VolunteerApplications}.css`, `feed/CategoryFilter.tsx`.

## Consolidation summary — one rule, not five

Five distinct things are currently implemented multiple ways. Each is already covered by a row above; this is the index.

1. **Card radius** — five answers: `var(--r)` 28 (`.card`, `.post-card`, `.stat`, `.modal`), `var(--r-outer)` 20 (the `!important` block that actually wins), `var(--hod-radius)` 20 (`.admin .card`, dead), 18 (`.pcard`, `.pbento-tile`), 16/20/22 (`.dept-ticket`, `.team-card`, `.pp-*`). → **`var(--r-card)`**. Rows P0-2, P0-3, P1-1..P1-7.
2. **Photo radius** — four answers: `calc(var(--r-outer) - 6px)` 14, literal 14, literal 20/16, `--r-xs` 6 (`.post-img`). → **`var(--r-photo)`**. Rows P0-2, P0-6, P1-5, P1-6.
3. **Depth** — ~25 hard-offset depths plus three soft-blur systems (`--sh-soft`, `--shadow-sm/-lg`, `--s1/--s2/--s3`). → **flat + `var(--bd)`, with `var(--shadow-cta)` on CTAs, stickers and one hero per screen**. Rows P0-7, P0-8, P1-14, P2-5, P2-8, P2-9.

5. **Icons** — hand-rolled inline SVGs, heroicons, and emoji, at 13 stroke weights. → **heroicons-24-outline at 1.8 / 2.5**. Rows P0-9, P1-13, P1-15.
